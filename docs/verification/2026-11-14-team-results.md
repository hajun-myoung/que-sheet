# 팀별 심사 현황

- 팀별로 행을 묶고 팀명 셀을 병합한다. 심사위원 1명은 기존 단일 행을 유지하며, 2명 이상은 평균 요약 행과 개별 평가 행으로 표시한다.
- 현재 배정된 심사위원의 최종 제출 점수만 평균에 포함한다. 0점은 포함하고 미작성·임시저장·재작성 중인 평가는 제외한다. 평가 기준 버전별로 평균을 분리하고 소수점 둘째 자리까지 표시한다.
- 심사위원 미배정 팀도 표시한다. 개별 재작성 허용 버튼은 유지한다.

검증: `npm run typecheck`, `node --import tsx --test tests/results.test.ts` (5개 통과), `npm run build -- --webpack` 통과. Safari에서 실제 Results 컴포넌트를 정적으로 렌더링한 검증용 데이터로 80점·100점의 평균 90점, 개별 행, 단일 심사위원 행, 미배정 표시를 확인했다. 운영 데이터 수정 및 실제 평가 재제출은 하지 않았다.
